## Conflicts and decisions

1. PETG cooling is product-specific: eSUN Matte 50–100% vs PolyLite PETG 0–20%. Keep both exact profiles; generic PETG does not masquerade as either.
2. Bambu machine presets contain broad allowable nozzle ranges (sometimes broader than product recommendations). Values above are baseline facts, not manufacturer safety guarantees; keep exact preset, verify spool range, and never increase heat to pursue speed.
3. X2D multi-value arrays encode multiple extruder variants. If all values agree, the scalar is used. If values differ, report “retain selected extruder preset” with the full array in provenance; no guessed array index.
4. Bambu profile AMS drying arrays differ from forced-air product instructions. Device-specific profiles are not interchangeable. UI drying values use forced-air source explicitly; AMS operation requires device/product compatibility confirmation.
5. eSUN PETG-Matte product page bed 60–70°C and TDS 70°C agree at the TDS endpoint. Use 70°C for PEI only. Drying duration, flow ratio and MVS are unknown; do not infer from melt flow index 17 g/10min.
6. Unknown brands (Overture, SUNLU, Other) and unrecognized exact profile names use clearly marked family fallback. They never inherit branded conditioning limits.
7. No community-derived numeric override is implemented. MakerWorld is a practical slice-preview/profile comparison resource, not a thermal authority. No recommendation relies on a fabricated community consensus.
