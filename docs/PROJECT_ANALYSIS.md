# Project-aware local analysis

The uploaded 3MF's saved project settings now populate material, recognized product/vendor, printer model, common nozzle diameter and configured filament count. A five-slot Generic PETG project selects PETG automatically instead of leaving the original PLA dropdown value active. Each configured slot keeps its own name/type/colour in an expandable summary. Slots are not claimed to be used on the selected plate.

Material family comes from saved filament_type, with specific known product names used to distinguish Matte/Silk when the saved base type is PLA/PETG. A recognized profile ID is usable when the type column is absent. Composite/unknown types are not silently mapped to plain PLA/PETG. Mixed or unresolved families select Other and request the material to advise on; a saved sliced result still supplies its original total grams. Geometry estimates with no known material density withhold the gram number. Unknown printer/nozzle data does not trigger a guess. STL contains geometry only, so material selection remains a confirmed user input. All auto-selected context remains editable.

Intended-use suggestions use explicit file-name clues: phone/smartphone holder/stand → Functional; coaster → Coaster only with corroborating flat proportions. These are labelled clues, not semantic shape recognition or a strength assessment.

Large geometry checks previously stopped at 200,000 triangles. Edge identities now use collision-free integer keys (vertex IDs are below 3N; at the new 400,000-face limit the key fits exactly in JS's integer precision). This reduces edge-key string allocations and lets bounded topology checks cover larger meshes. Volume is still accepted only for a single consistently wound closed shell without duplicates or non-manifold edges. Multiple shells/overlaps/cavities remain unverified; no bounding-box replacement or summed absolute-shell volume is invented. Above the bound the existing surface-only fallback is clearly marked. This is not full intersection testing or slicing.

The default results now show a concise file summary, automatic time/grams and selected actionable recommendations. Calibration/preset filler and the complete seven-tab library are under All Studio controls & current settings. Main/Auxiliary speed recommendations remain separate. Reasons and Studio paths expand per setting instead of filling the page. The large generic speed-education card has been removed. Geometry statistics are also expandable.

No external model service, Hugging Face dependency or file upload is introduced. Saved filament identity is read directly rather than inferred from a rendered colour. A learned object classifier would not establish actual filament, wall strength, support accessibility or printer tool-change time. The lightweight estimate and saved-slice distinction remain in place.
